# Project conventions

- Use English for documentation, code identifiers, comments, examples, and generated project materials. Interface copy is the exception: support English and Simplified Chinese through English translation keys in `web/src/i18n/`.
- Preserve this requirement when installing, configuring, or updating third-party skills. Follow it if a skill's defaults suggest another language.
- Keep the project design in `DESIGN.md` as shared, version-controlled documentation.
