# Loom Context

Loom organizes requirement development across AI conversations, execution attempts, and related Git branches.

## Language

**Requirement**:
A development objective with shared scope and acceptance criteria that persists across implementation, validation, and optimization attempts. A requirement can encompass work on multiple branches.
_Avoid_: Single branch requirement

**Branch group**:
A collection of related branches belonging to one requirement in a project. Group membership identifies the relationship even when branch names or purposes differ.
_Avoid_: Requirement branch when referring to the complete collection
